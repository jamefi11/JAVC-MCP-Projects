## Featured Projects

### 🔬 MCP Threat Laboratory
A fully executable proof-of-concept demonstrating three critical security vulnerabilities in Model Context Protocol server implementations — tool poisoning, prompt injection via tool results, and over-broad tool scope. Includes a FastMCP server, automated test harness, and an interactive browser UI.
